# 原方案重装前私密备份

适用于目前运行正常、采用本仓库历史路径的 Debian 13 amd64 原方案。供应商快照若在重装后不保留，不能用作重装退路；备份必须下载到你自己的电脑。

`tools/export_legacy_recovery.sh 证书域名` 只检查并导出当前文件，不安装、不重启、不签发证书、不更改 DNS 或防火墙。

工具要求 Nginx 和 V2Ray 当前运行、配置检查通过、现有证书链/域名/有效期合格、Nginx 与磁盘证书一致。缺少已审核路径或出现新版混装时停止。它保存 Nginx/V2Ray 配置及程序、acme.sh 目录、实际 systemd 服务文件及 drop-in、软件包清单及 root cron 记录。GNU tar 完成后与源文件比较，发现并发变化时不报告成功。

输出 `/root/legacy-proxy-recovery.tar.gz` 和旁边的 `.sha256`。二者不会覆盖已有文件；制作中的私密目录保留用于核对。压缩包包含证书私钥、节点 UUID 和 Cloudflare 凭据，权限限制为 root，未加密。请只通过 SSH/SCP 下载到自己的私密目录，不要上传 GitHub、聊天或共享盘。不要在电脑上双击执行归档内文件。

`BACKUP_CREATED` 只表示已生成和比对文件。它不是完整系统镜像，不是实机恢复通过，也不证明公网客户端正常。源系统仍在运行，文件导出无法提供整机快照的所有一致性保证。现有 acme.sh 凭据可能已经失效，备份不会修正它们。

下载并比对 SHA-256 后，需要根据工具输出的服务路径、用户、包依赖审核恢复流程。恢复目标必须为干净 Debian，不能直接把压缩包覆盖到新版 WARP 或其他已运行系统。不要盲目恢复整个 root crontab、系统网络、SSH 或防火墙。当前尚未提供经过实机验收的自动恢复器。

工具会打印可反馈的服务路径和 User/Group 等字段；不要反馈备份正文、完整配置或服务定义文件。完成恢复验证前，不应因备份提示成功就删除唯一可用系统。
